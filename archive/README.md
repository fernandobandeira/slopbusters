# Archive

The original opencode setup, kept for reference and inspiration. None of it is installed by the plugin.

- `opencode/agents/`: the agent personas (Ana, Archie, Paul, Ulysses, Dev, SM, Rita) and subagents
- `opencode/legacy-skills/`: the old opencode skills. The folder was renamed from `skills/` so that skill installers (`npx skills`, `gh skill`) don't pick them up.
- `templates/`: per-role document templates and the project `AGENTS.md`

New skills live in `/skills` at the repo root.
